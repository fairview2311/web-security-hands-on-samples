# 第14章　パストラバーサル（../ でサーバーのファイルを読む）

本の第14章を終えた時点の演習アプリ「みどりメモ」です。本のコードの枠の上の「サンプルコード　ch14/…」は、このフォルダーのファイルを指します。

この章でできるようになること:

- パストラバーサルを直し、基準のフォルダーの中かを確かめてからファイルを返すようにした

## この章での使い方

起動には Docker Desktop が必要です。コマンドは、Windows は PowerShell、Mac はターミナルで実行します。サンプルコードはホームのフォルダーなどに展開してください。

1. このフォルダーでターミナル（Windows は PowerShell）を開き、みどりメモを起動します。初回はイメージの作成に数分かかります。

   ```text
   docker compose up -d --build
   ```

2. ブラウザで下の URL を開いて確かめます。

3. 確かめ終わったら、同じフォルダーでコンテナを停止します。

   ```text
   docker compose down
   ```

## うまくいったかの確かめ方

- http://localhost:8000/ … ../ を使ってもサーバーの設定ファイルを読めないことを確かめる

動作しないときは、本の第14章の「うまくいかないとき」を見てください。
