# 第2章　演習用のアプリをローカル環境で起動する

本の第2章を終えた時点の演習アプリ「みどりメモ」です。本のコードの枠の上の「サンプルコード　ch02/…」は、このフォルダーのファイルを指します。

この章でできるようになること:

- みどりメモが Docker で起動し、ブラウザで開ける
- ホーム・掲示板・検索・地図・API 操作・ログインの画面がある

## この章での使い方

起動には Docker Desktop が必要です。コマンドは、Windows は PowerShell、Mac はターミナルで実行します。サンプルコードはホームのフォルダーなどに展開してください。

1. このフォルダーでターミナル（Windows は PowerShell）を開き、みどりメモを起動します。初回はイメージの作成に数分かかります。

   ```text
   docker compose up -d --build
   ```

2. ブラウザで下の URL を開いて確かめます。

3. 確かめ終わったら、同じフォルダーでコンテナを停止します。

   ```text
   docker compose down
   ```

## うまくいったかの確かめ方

- http://localhost:8000/ … みどりメモのホーム画面
- http://localhost:8000/docs … FastAPI が自動で生成した API の一覧

動作しないときは、本の第2章の「うまくいかないとき」を見てください。
