# 第3章　HTTPとCookieとセッションをのぞく

本の第3章を終えた時点の演習アプリ「みどりメモ」です。本のコードの枠の上の「サンプルコード　ch03/…」は、このフォルダーのファイルを指します。

この章でできるようになること:

- 開発者ツールで、ログインの通信と Cookie・セッションを確かめられる

## この章での使い方

起動には Docker Desktop が必要です。コマンドは、Windows は PowerShell、Mac はターミナルで実行します。サンプルコードはホームのフォルダーなどに展開してください。

1. このフォルダーでターミナル（Windows は PowerShell）を開き、みどりメモを起動します。初回はイメージの作成に数分かかります。

   ```text
   docker compose up -d --build
   ```

2. ブラウザで下の URL を開いて確かめます。

3. 確かめ終わったら、同じフォルダーでコンテナを停止します。

   ```text
   docker compose down
   ```

## うまくいったかの確かめ方

- http://localhost:8000/login … ログインの画面（開発者ツールで通信を見る）

動作しないときは、本の第3章の「うまくいかないとき」を見てください。

第2章から変更したファイルはありません。
