# 16の攻撃と対策で学ぶWebセキュリティ サンプルコード

書籍『16の攻撃と対策で学ぶWebセキュリティ 脆弱性を試して防ぐハンズオン』の演習アプリ「みどりメモ」のサンプルコードです。

## 書籍

- Kindle 版: https://www.amazon.co.jp/dp/B0HQQQLMWB
- ペーパーバック: https://www.amazon.co.jp/dp/B0HQTQ15TL

## 動かすのに必要なもの

- Docker Desktop（みどりメモは Docker で動きます）
- ブラウザ（Chrome・Edge・Safari など）

VS Code と Dev Containers 拡張機能を使うと、本のとおりにコンテナの中でコードを編集できます。インストールの手順は本の第2章にあります。

## このサンプルコードについて

**みどりメモは、学習のために 16 個の脆弱性をわざと入れた演習アプリです。** インターネットに公開するサーバーや本番の環境では、絶対に動かさないでください。各章のフォルダーには、その章を終えた時点のみどりメモが入っています。

章ごとのフォルダー（`ch04` など）は、その章で脆弱性を1つ対策した状態です。自分の直し方が分からなくなったときや、途中の章から読み始めるときに使います。

## ファイルを入手する方法

このリポジトリの緑の「Code」ボタンから ZIP をダウンロードするか、`git clone` で取得します。章ごとの状態だけが必要なときは、各章のタグ（`ch06` など）の ZIP を、リポジトリの「Releases」や「Tags」から取得できます。

取得したら、ホームのフォルダーなどに展開します。

## 本のコードとファイルの対応

本文のコードの枠の上には「サンプルコード　ch06/app/...」のように、このリポジトリの中の場所が書いてあります。本に載っているコードは、すべてこのサンプルコードの中にあります。本とサンプルコードは、1文字も違わないように作っています。

## 知っておくこと

- みどりメモの脆弱性は、FastAPI の欠陥ではありません。学習のためにわざとそう書いた、アプリのコードが原因です。同じ穴は、どの言語・フレームワークでも起こります。
- 各章のフォルダーの `attacker/tests` には、その章までの攻撃が通らないことを確かめる pytest のテストが入っています。
- 攻撃は、自分のパソコンの中で動くみどりメモにだけ向けてください。他人のサイトや許可を得ていないシステムには、絶対に試さないでください。
