# 第20章　自動の診断とチェックリストで守り続ける

本の第20章を終えた時点の演習アプリ「みどりメモ」です。本のコードの枠の上の「サンプルコード　ch20/…」は、このフォルダーのファイルを指します。

この章でできるようになること:

- 16 個の脆弱性をすべて対策し、セキュリティヘッダーを追加した最終形のみどりメモ
- 16 個の攻撃が通らないことを確かめる pytest のテストがそろっている

## この章での使い方

起動には Docker Desktop が必要です。コマンドは、Windows は PowerShell、Mac はターミナルで実行します。サンプルコードはホームのフォルダーなどに展開してください。

1. このフォルダーでターミナル（Windows は PowerShell）を開き、みどりメモを起動します。初回はイメージの作成に数分かかります。

   ```text
   docker compose up -d --build
   ```

2. ブラウザで下の URL を開いて確かめます。

3. 確かめ終わったら、同じフォルダーでコンテナを停止します。

   ```text
   docker compose down
   ```

## うまくいったかの確かめ方

- http://localhost:8000/ … すべての対策が入った状態で動く

動作しないときは、本の第20章の「うまくいかないとき」を見てください。
